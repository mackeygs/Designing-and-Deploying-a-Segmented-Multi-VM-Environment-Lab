# Designing-and-Deploying-a-Segmented-Multi-VM-Environment-Lab
Homelab project building a segmented virtual infrastructure in VirtualBox: a Linux server, a Windows workstation, and an isolated Linux test system reachable only through a jump box. I used it to test VM resizing, cloning, snapshot rollback, and virtual storage, plus a bonus Pi-hole Docker container to compare containers with VMs.
